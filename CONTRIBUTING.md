# Как участвовать

Спасибо за интерес. Проект небольшой, правила простые.

## Ошибки и идеи

Создайте issue по шаблону. Для ошибок приложите версию, версию Windows и последние строки журнала `%LOCALAPPDATA%\RecallSearch\recall.log` без личных путей.

## Изменения в коде

1. Сделайте форк и ветку от `main`.
2. Соберите и запустите тесты: `dotnet test`. Инструкции: [docs/development.md](docs/development.md).
3. Пишите тест вместе с изменением. Тесты лежат в `tests/`.
4. Предупреждения компилятора считаются ошибками (`TreatWarningsAsErrors`). Сборка должна проходить без них.
5. Если меняется поведение, обновите [руководство](docs/guide.md) и [CHANGELOG.md](CHANGELOG.md).
6. Откройте pull request по шаблону. Один PR - одно изменение.

## Принципы проекта

- Всё локально. Новые сетевые запросы и телеметрия не принимаются, кроме скачивания моделей по явному выбору пользователя.
- Секреты не читаются и не индексируются. Это правило нельзя ослаблять настройкой.
- Агент не мешает работе: пониженный приоритет, пауза в играх и презентациях.

Участвуя, вы соглашаетесь, что ваш вклад распространяется по лицензии [MIT](LICENSE).
