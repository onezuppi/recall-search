# Идеи на будущее

Здесь собраны функции, которые пока не вошли ни в один план. Реализованное сюда не попадает.

## Векторы в памяти и быстрый поиск

Сейчас поиск по смыслу читает векторы из SQLite через JOIN, около 8 мкс на строку (см. `docs/benchmarks/2026-11-plan2-embeddings.md`). Около 40 тысяч строк это уже 300 мс. Нужно:

- держать таблицу векторов в памяти в компактном виде (float16 или int8) или читать `embeddings` без JOIN и разрешать пути только для лучших сегментов;
- решить, когда эту таблицу сбрасывать, чтобы не хранить сотни мегабайт постоянно.

## Устройства GPU и NPU для эмбеддингов

Поле `EmbeddingDevice` уже есть в конфиге, но поддержан только CPU. Для GPU нужен DirectML, для NPU порт Taconite. Перед включением проверить совместимость векторов разных устройств (косинус не ниже 0.999).
